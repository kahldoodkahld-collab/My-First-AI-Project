ماذا سأتعلم؟

- البرمجة من الصفر.
- الذكاء الاصطناعي وأدواته.
- تطوير التطبيقات ومواقع الويب.

- استخدام ChatGPT وواجهات OpenAI API.

مجالات مشاريعي

1. مشاريع الذكاء الاصطناعي

تجربة أفكار وأدوات ذكية تساعد على إنجاز المهام والتعلم.

2. الصور والفيديو

التعرف إلى أدوات إنشاء الصور وتحريكها وصناعة الفيديو بالذكاء الاصطناعي.

3. تعلم البرمجة

التدرّب تدريجياً على HTML وCSS وJavaScript وPython.

4. ربط ChatGPT وOpenAI

تعلم أساسيات واجهات API وكيفية استخدامها بطريقة آمنة.

5. تطوير التطبيقات

بناء تطبيقات بسيطة للويب والهاتف وتطويرها مع الوقت.

سجل التعلم والتطوير

سأضيف هنا ما أتعلمه من دروس، وما أنجزه من مشاريع وتحديثات.

هدفي

تعلم بناء مشاريع حقيقية خطوة بخطوة، من الفكرة إلى التجربة والتطوير.

قواعد الأمان

- لا أشارك كلمات المرور أو رموز التحقق.
- لا أنشر مفاتيح API السرية داخل المستودع.
- أستخدم ملفات إعدادات آمنة عند الحاجة إلى مفاتيح سرية.
- أتعلم وأطور مشاريعي باستمرار.
